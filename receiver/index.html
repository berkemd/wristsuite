Keyboard & mouse fallback

  • → Space Page Down — next page (same as a forward flick)
  • ← Page Up — previous page (same as a back flick)
  • B — black screen on/off (same as a twist)
  • F — full screen on/off
  • Esc — leave full screen, or clear the black screen
  • Home End — first / last page
  • Click the right side of the deck for next, the left edge for previous.

A next/previous also lifts the black screen, so you never advance blind. The screen-wake lock is requested while a deck is open, so the display should not sleep mid-talk.

What this page can and cannot drive

This page is the presenter: it renders your deck itself, so a gesture always lands on the slide you are looking at. It cannot drive Keynote, PowerPoint, Google Slides or any other app or browser tab — a web page is not allowed to send key presses outside itself, and that is a browser security rule, not a setting. Export your deck to PDF and open it here instead (Keynote: File → Export To → PDF; PowerPoint: File → Export → PDF; Google Slides: File → Download → PDF). The PDF is read locally with the File API and rendered on this page — it is never uploaded, and there is no server anywhere in the chain. If you would rather keep presenting from your own software, leave this page open on a second screen and use the live gesture panel as a monitor.

Rendering uses pdf.js 4.10.38 loaded from cdnjs.cloudflare.com, fetched only when you open a PDF.

About the Bluetooth section / Bluetooth bölümü hakkında

“Connect watch” cannot reach an Apple Watch today. The button and the Web Bluetooth code below it are left in place, but there is nothing on the watch side to connect to: an Apple Watch cannot act as a Bluetooth LE peripheral, so it cannot advertise the GATT service this page looks for. That is a watchOS platform limit, not a setting you can change and not something a browser flag fixes — the browser is a BLE central as well, and two centrals cannot form a connection. The GesturAir watch app is therefore not published, and its transport layer is being redesigned; no release date is promised here.

What still works: this page remains a working PDF presenter. Open a deck, then use the keyboard shortcuts above, click the left and right zones of the slide, or press the N / P / T buttons in the live gesture panel. Your file is read locally with the File API and is never uploaded.
