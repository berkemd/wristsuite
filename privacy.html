Privacy Policy

Norea Studio — Berke Kahraman · Last updated 31 August 2026

This website collects nothing. It is a set of static pages served by GitHub Pages. There is no account, no login, no analytics, no advertising, no tracking pixel and no cookie set by us.

Each app is separate. Every app has its own privacy page stating exactly what that app does and does not collect. This page does not speak for them; the app's own page does.

The website

These pages are static HTML hosted on GitHub Pages. We do not run a server, a database or an analytics service, and we do not place cookies. We therefore hold no record of your visit.

GitHub, as the host, may process standard server request information (such as IP address) for the purpose of serving and protecting the site. That processing is GitHub's, under GitHub's Privacy Statement, and we receive none of it.

Every app also carries an App Privacy label on its App Store page, which Apple displays before you install.

Our social accounts

We publish announcements about our own apps to our own accounts on X, Pinterest and Telegram, from an automated pipeline that we run ourselves.

That pipeline is publish-only. It does not read, collect, store or analyse any data from those platforms: it does not retrieve posts, profiles, followers, timelines, boards or search results, and it does not read anything about the people who see or interact with our posts. The only thing it records is a checksum of our own published text, used solely so the same announcement is never posted twice. No platform data of any kind is shared with anyone, because none is ever retrieved.

If you interact with one of our posts, that interaction is governed by that platform's own privacy policy, not this one.

Children

Where an app is offered in the App Store Kids Category, it is built so that it collects no data at all, requests no permissions, and makes no network requests. The relevant app's own privacy page states this specifically, and Apple's Kids Category rules apply to it in addition to this policy.

Your rights

We hold no personal data about you, so there is nothing for us to export, correct or delete. If you believe otherwise, write to us and we will answer.

Changes

If this policy changes, the date at the top changes with it. Material changes will also be noted on the relevant app's own page.
